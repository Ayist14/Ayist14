* [Dictionary Library](https://snap.berkeley.edu/project?username=ayist14&projectname=Dictionary%20Library%20for%20Snap%21%2012%2b) (Snap<em>!</em> 12.0.0+)

  It's the latest one published on August 3, 2026. I released it at community because I can't stand the strange actions of `item [index] of [list]` reporter (see [Snap<em>!</em> 12's log](https://github.com/jmoenig/Snap/releases/tag/v12.0.0)) and the "dictionary" that is regarded as a data object in parallel (see [Snap<em>!</em> 10.1's log](https://github.com/jmoenig/Snap/releases/tag/v10.1.0)).
  
  As the title at website mentioned, It's bulit by **ADT (Abstract Data Type)**. So you can build your project with them as *truth* dictionaries.
